# STUDY-GUIDE
# The Computer Was Never Just a Machine

An interactive study artifact exploring the history of
computing through human labor, automation, programming,
representation, and the human-machine relationship.

## Course
UNC Charlotte — Computing

## Format
Interactive visual study guide

## Core Question
Who — or what — gets to be called a computer?

## Concepts
- Computing
- Representation
- Automation
- Punched cards
- Human computers
- Programming
- ENIAC
- Computational labor
- Human-machine systems

## Why I Made This

Instead of creating a traditional study guide, I wanted to
turn the readings into a visual system that I could actually
remember.

The central idea is that the meaning of "computer" changes
throughout computing history.
